GUARDIANES DE HISTORIAS

Sesión 1

Tarea 1: Visualización y Debate

Duración
1 hora
Parejas/Tríos
25 alumnos

Cómo sabéis vamos a comenzar la situación de aprendizaje de esta última evaluación. Para ello, en esta primera sesión, vamos a visualizar una serie de fragmentos y haremos un debate inicial.

-Primero, visualiza el vídeo que tienes abajo, en la sección: "Sitio web externo".

-Segundo, comentaremos qué hemos visto e iniciaremos el debate inicial.

-Tercero, rellena la lista de cotejo y responde a la pregunta del diario o reflexión.


Sitio web externo

No se puede mostrar un iframe en HTTP en una web HTTPS.

Herramientas

Las herramientas que debes usar para hacer esta actividad son:

- Google Docs

- Word online

Criterio de evaluación. Sesión 1

El criterio de evaluación que se va a evaluar en esta primera sesión será:

3.1: Planificar la redacción de textos narrativos y descriptivos (relato corto), siguiendo las convenciones del género y ajustándose a la intención comunicativa.

Instrumento de evaluación: Lista de cotejo

Completa la lista de cotejo marcando las casillas al realizar las actividades correspondientes.
